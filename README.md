# 🍽️ Zomato – Food Discovery Platform

A MERN stack food discovery application inspired by Zomato, where users can explore food partners, discover dishes through reels, and interact with food content.

## ✨ Features

- **Food Reels:** Explore food videos in an interactive reels-style feed.
- **Discover:** Search restaurants and dishes with food category filters.
- **Food Partners:** Browse food partners and their stores.
- **Interactions:** Like, comment, save and report reels.
- **User Profile:** Manage profile information and account settings.
- **Saved Reels:** Access your bookmarked food videos.
- **Theme Preferences:** Switch between light, dark and system appearance.

## 🛠️ Tech Stack

- React.js
- Node.js
- Express.js
- MongoDB
- CSS
- REST APIs

## 🚧 Upcoming Features

- Food ordering and order management.
- Food ratings and reviews.

## 🎯 Project Goal

To build an interactive food discovery platform that combines short-form food videos with restaurant exploration and user engagement.
